# isMaid



Checks whether a value is a valid Maid instance.

### Syntax

```lua
Maid.isMaid(value: any) -> boolean
```

***

### Parameters

| Parameter | Type  | Description    |
| --------- | ----- | -------------- |
| `value`   | `any` | Value to check |

***

### Example

```lua
print(Maid.isMaid(Maid)); -- true
```
