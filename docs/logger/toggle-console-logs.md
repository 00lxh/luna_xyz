# ToggleConsoleLogs





Enables or disables console output.

### Syntax

```lua
Logger:ToggleConsoleLogs(value: boolean) -> nil
```

***

### Parameters

| Parameter | Type      | Description                          |
| --------- | --------- | ------------------------------------ |
| `value`   | `boolean` | Whether logs should print to console |

***

### Example

```lua
Logger:ToggleConsoleLogs(false);
```
