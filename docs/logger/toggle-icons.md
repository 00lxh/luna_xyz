# ToggleIcons





Enables or disables icons in logs.

### Syntax

```lua
Logger:ToggleIcons(value: boolean) -> nil
```

***

### Parameters

| Parameter | Type      | Description                       |
| --------- | --------- | --------------------------------- |
| `value`   | `boolean` | Whether icons should be displayed |

***

### Example

```lua
Logger:ToggleIcons(false);
```
