# success







Creates a log and returns a **log module** for dynamic control.

### Syntax

```lua
Logger.success(message: string) -> LogModule
```

***

### Parameters

| Parameter | Type     | Description    |
| --------- | -------- | -------------- |
| `message` | `string` | Message to log |

***

### Example

```lua
local log = Logger.successt("Player joined");
```
